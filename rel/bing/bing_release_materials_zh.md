## 二、各步骤需要填写的材料

### 步骤 1：注册开发者账号
- Microsoft 账号登录合作伙伴中心
- 注册 Microsoft Edge 扩展开发者计划：**免费**（企业账号需额外验证）
- 开发者/组织显示名称（公开展示）
- 联系邮箱（供用户反馈，公开显示）

### 步骤 2：构建并打包 ZIP
```powershell
npm install
npm run build
Compress-Archive -Path manifest.json, _locales, src, res, dist -DestinationPath release/cat-eyeing-mouse-v1.0.0.zip -Force
```
- ZIP 根目录必须直接可见 `manifest.json`（无嵌套目录）
- 必须包含：`manifest.json`、`_locales/`、`src/`、`res/`、`dist/content.js`
- 必须排除：`doc/`、`node_modules/`、`.trae/`、`readme.md`、`package*.json`
- 包体积 ≤ 2MB
- 注意：上传后 Partner Center 会根据 `_locales` 自动识别出 English 与中文（简体）两个语言列表

### 步骤 3：创建新扩展并上传

- 校验失败时按提示修正后重新上传

### 3.3 商店列表详细描述
> 必须 250 - 10000 字符，manifest 中的短描述不满足下限，请用以下全文替换。

```
猫盯鼠标——把一只软萌的小猫带到每一个网页里。

安装后，一只可爱的小猫会悬浮在页面右下角，用眼神和姿态实时追随你的鼠标移动，仿佛一只专注的猫咪正盯着自己的"猎物"。它不只是一件装饰，更是一个有生命感的桌面宠物：

【核心功能】
• 8 方向姿态跟踪：小猫根据鼠标方位实时切换 8 个朝向；鼠标移到它身上时，会进入专注的中心注视态
• 平滑过渡动画：基于 Canvas 交叉淡入淡出渲染，姿态切换丝滑无跳变
• 自由拖拽：按住小猫即可拖到页面任意位置，位置自动记忆，刷新页面不丢失
• 智能休息：鼠标静止 10 秒后，小猫会舒服地靠下休息；一动鼠标立刻精神抖擞
• 一键显隐：点击工具栏图标即可显示/隐藏小猫，还可开启视口边界约束，防止把猫咪拖丢
• 中英双语：自动适配浏览器语言，中文/英文界面开箱即用

【隐私与性能】
• 零数据收集：纯本地运行，无任何网络请求、无埋点、无数据上报
• 零配置：安装即用；Shadow DOM 完全隔离，不改动网页内容与样式
• 极致轻量：标签页隐藏时自动暂停渲染，鼠标静止时 CPU 占用接近 0%

【温馨提示】
出于浏览器安全限制，浏览器内置页面（如 edge:// 设置页、Edge 加载项商店页面、PDF 查看器）中不会出现小猫，属正常现象。

如果你也想要一只永远盯着鼠标的小猫咪，现在就把它带回家吧！
```

### 3.6 权限理由
| 权限 | 填写内容 |
|------|----------|
| storage | 仅在用户本地 chrome.storage.local 保存猫咪悬浮位置与用户设置（显示/隐藏、边界约束），不上传任何数据。 |
| tabs | 将用户在工具栏弹窗中做出的显示/隐藏、边界约束开关操作，同步到已打开标签页中正在运行的猫咪悬浮层，使设置即时生效。不读取、不记录任何浏览数据。 |

### 3.9 隐私政策（全文）
> 托管到 GitHub 仓库或个人网站后，将 URL 填入"隐私政策 URL"字段。

```
猫盯鼠标（Cat Eyeing Mouse）隐私政策

最后更新：2026-08-16

我们非常重视你的隐私。本扩展不收集、不传输任何用户个人数据。

一、数据收集
本扩展不收集任何个人信息，包括但不限于浏览记录、输入内容、身份标识、位置信息。
本扩展不发起任何网络请求，无埋点、无统计、无数据上报。

二、本地存储
扩展仅在你的浏览器本地（chrome.storage.local）保存两类数据：
1. 猫咪的悬浮位置（键名 cem.position）
2. 你的显示/隐藏与边界约束设置（键名 cem.settings）
这些数据不会上传到任何服务器，卸载扩展后即被自动清除。

三、权限说明
- storage：用于在本地保存上述位置与设置；
- tabs：用于将你在弹窗中的开关操作同步到已打开的标签页；
- 所有网站访问（<all_urls>）：猫咪需要在你访问的任意网页上渲染悬浮层，
  扩展不读取、不修改任何页面内容。

四、第三方与远程代码
本扩展不接入任何第三方服务，不包含广告与统计 SDK，不执行任何远程代码。

五、政策变更
如未来功能变化涉及数据处理，我们将在更新说明中明确告知。

联系方式：[填写你的邮箱]
```
